# 04 - 部署与迭代

## 部署命令

```bash
lerobot-rollout \
  --strategy.type=base \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.id=oye_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: 2, width: 1920, height: 1080, fps: 30, fourcc: MJPG}}" \
  --rename_map='{"observation.images.front": "observation.images.camera1"}' \
  --display_data=true \
  --duration=300 \
  --task="Pick up the tissue roll wrapped with orange-yellow tape on the wooden table and place it on the blue-purple area" \
  --policy.path=/home/lbc/output_lerobot_train/tissue/smolvla_v2/checkpoints/last/pretrained_model
```

## 可视化：Rerun

LeRobot 0.6.1 的 `--display_data=true` 默认走 **Rerun**（rerun.io，rerun-sdk 随 LeRobot 安装）：
- 相机画面 + 机器人状态时间轴，可回放
- 录制演示视频的好工具（本项目录屏即 Rerun 窗口）

数据回看用 `lerobot-dataset-viz`（注意：不是 `lerobot-visualize-dataset`，0.6.1 已改名）。

## 部署要点（全部踩过）

1. **task 口令一字不差**：VLA 认字不认意思，训练/部署不一致会行为漂移
2. **相机编号**：`index_or_path` 填实际设备（`ls /dev/video*` 确认；本项目为 video2）
3. **1080p + MJPG**：分辨率与训练一致（防误判距离），MJPG 保帧率（防 YUYV 5fps 抽搐）
4. **`--rename_map` 训练/部署成对出现**：训练时改了数据集钥匙孔，部署时机器人这边要用同一把钥匙
5. **连续测试**：base 策略无 `num_episodes`（那是 dagger 模式的），用 `--duration=秒` 控制时长

## 迭代流程

```
部署 → 观察失败模式 → 对照训练数据（lerobot-dataset-viz）→ 定位是数据问题还是场景问题
     → 补录数据 / 恢复场景 → 合并数据集 → 重新微调 → 再部署
```

本项目完成一轮完整迭代：悬空夹 → 补录"贴着夹"演示 → v2 微调 → 部署成功（详见 05-实验记录）。
