# 03 - 模型训练

## 训练配置

基于预训练模型 `lerobot/smolvla_base`（450M）微调：

```bash
lerobot-train \
  --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=oye-Li-bc/oye \
  --dataset.root=/home/lbc/.cache/huggingface/lerobot/oye-Li-bc/oye_tissue_v3_20260825_161500 \
  --rename_map='{"observation.images.front": "observation.images.camera1"}' \
  --policy.empty_cameras=2 \
  --output_dir=/home/lbc/output_lerobot_train/tissue/smolvla_v2 \
  --job_name=tissue_smolvla_v2 \
  --policy.device=cuda \
  --wandb.enable=false \
  --policy.push_to_hub=false \
  --steps=20000 \
  --batch_size=8
```

## 关键参数说明

| 参数 | 值 | 原因 |
|---|---|---|
| `--rename_map` | front → camera1 | 数据集相机名（front）与模型预训练特征名（camera1/2/3）不一致 |
| `--policy.empty_cameras=2` | 2 | 单相机 + 2 个空相机位，凑齐 3 图输入（官方 aloha_sim 同款做法） |
| `--batch_size=8` | 8 | 11.5GB 显存实测可行（模型仅占 0.9GB） |
| `--steps=20000` | 20000 | 官方推荐量级；140W 下约 1.5~2 小时（~3.8 step/s） |
| `--policy.push_to_hub=false` | false | 权重先留本地，验证后再上传 |

## 显存实测

- 模型加载：**0.9 GB**（450M 参数 bf16）
- 可训练参数：**~100M**（视觉编码器冻结 + 仅动作专家可训）
- 训练峰值：**5.12 GB**（batch=8，输入 512×512）

## 踩坑记录

1. **`--policy.path` 与 `--policy.type` 冲突**：0.6.1 校验不允许同时指定（path 可自动推断 type），子豪哥教程的旧版命令需删掉 `--policy.type=smolvla`
2. **`--resume=true` 报错**：`Optimizer config is required but not provided`——0.6.1 resume 不恢复 optimizer 配置；直接从头训（20000 步 90 分钟，成本可接受）
3. **`~` 不展开**：`--dataset.root=~/...` 中 tilde 原样传给程序（bash 只在词首展开 `~`），必须用绝对路径
4. **feature 校验**：数据集 `{front}` 与模型 `{camera1,2,3}` 互不包含 → 报 mismatch；`rename_map` 后数据集成为模型子集即通过

## 训练曲线

训练过程未开 wandb，loss 每 200 步打印于终端。建议后续训练开启 `--wandb.enable=true` 以留存曲线。
