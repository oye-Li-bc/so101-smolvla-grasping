# 01 - 项目概述

## 背景

在完成 [so101-act-grasping](https://github.com/oye-Li-bc/so101-act-grasping)（ACT 模仿学习全流程）之后，希望进一步探索**视觉-语言-动作模型（VLA）**路线：利用大规模预训练的 VLA 权重，在低成本机械臂上做小样本微调，验证"预训练先验能否带来动作质量增益"。

## 目标

1. 在 SO-ARM101 上用 SmolVLA 微调完成纸巾卷抓取-放置任务
2. 与 ACT 基线做同任务对比，评估 VLA 路线的可行性
3. 完整记录工程链路（数据→训练→部署→迭代），形成可复现仓库

## 技术选型

| 维度 | 选择 | 理由 |
|---|---|---|
| 基础模型 | SmolVLA（450M） | HuggingFace 轻量 VLA，消费级显卡可微调（官方 8GB 起步） |
| 框架 | LeRobot 0.6.1 | 原生支持 smolvla policy，与 ACT 工作流无缝衔接 |
| 硬件 | RTX 5070 Ti 11.5GB | 冻结视觉编码器后显存充足，实测 batch=8 |

## 与 ACT 路线的区别

| | ACT | SmolVLA |
|---|---|---|
| 学习方式 | 纯行为克隆（CVAE + Transformer） | VLA：视觉 + **语言指令** + 动作专家（Flow Matching） |
| 先验 | 无（从零学） | 预训练 10k+ 小时机器人数据 |
| 输入 | 图像 + 状态 | 图像 + 状态 + **语言指令** |
| 参数量 | 52M | 450M（可训练约 100M） |
| 显存需求 | 低 | 低（冻结 VLM + 只训专家） |

## 核心结论（详见 05-实验记录）

- SmolVLA 在低成本臂上**可微调、可部署**，夹取动作质量**优于 ACT 基线**
- 泛化能力受限于**数据多样性与单目视角**（诚实边界）
- 完整 debug 闭环：从"悬空夹失败"到"数据驱动修复成功"
